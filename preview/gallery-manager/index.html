Connect GitHub

Authorise uploads to your own repository.

Your token is kept in this app's memory only. It's never saved in the public website files or sent anywhere other than GitHub.

How do I create my access token?
  1. Open GitHub's fine-grained token page and sign in.
  2. Choose account ksgarden26 as resource owner.
  3. Select Only select repositories and choose ks-price-calculator.
  4. Under Repository permissions, give Contents: Read and write. Leave other permissions at their defaults.
  5. Generate the token, copy it into the box above and tap Connect.

Set an expiry date you'll remember. When it expires, create a new one. Never share your token in messages or screenshots.
