# KS Garden Services website rebuild

This folder contains the standalone KS Garden Services website being prepared to replace the current hosted-builder site.

## Current status
- Mobile navigation
- Services, areas, reviews, news, about and contact pages
- Privacy and cookie information
- Consent controls with essential / analytics / marketing choices
- Contact form connected to the existing enquiry endpoint
- Existing calculator retained outside this folder until final migration

## Safety
The rebuild is developed on the `website-rebuild` branch. The current live calculator on `main` has not been replaced.
